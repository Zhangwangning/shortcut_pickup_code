# shortcut_pickup_code

#### Description
快递取件码快捷指令
通过 iOS 快捷指令的自动化功能，自动匹配短信内容，提取其中的快递取件码和取件地址，并自动添加到系统提醒事项列表中。纯本地运行，无需第三方服务。
