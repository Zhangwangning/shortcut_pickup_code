# 快递取件码 V7.1.0

> **作者**：极客ZHANG（张王宁）
> **发布日期**：2026-08-08
> **版本号**：7.1.0（versionCode: 710）
> **动作数**：115 个（较 V7.0.0 的 93 个增加 22 个）
> **定位**：V7 系列**首个公开发布版**，核心价值是「装上在线更新能力」

## 版本定位

V7.1.0 是 V7 系列的**第一个对外公开发布版本**。它的前身上 V7.0.0（2026-08-03）完成了正则架构重构——五套正则字典化、新增快递平台识别、取件地址拆为地址1/地址2——但**仅做架构改造、未公开发包**（无 iCloud / 二维码）。

V7.1.0 在 V7.0.0 的基础上做了两件事：
1. **正式对外发布**：提供 iCloud 下载链接 + 仓库二维码，普通用户可一键安装；
2. **新增「在线更新检查」机制**：这是 V7 与之前所有版本（V1.0 ~ V6.4）的**根本分水岭**。

> 因此 V7.1.0 在**正则层面没有新东西**，它的价值是"公开发布 + 在线更新"。正则内容的进化要等到 V7.1.3。

## 获取方式（已停止分发）

> 本版本自 **2026-09-20** 起停止分发，仓库已移除二维码与 iCloud 链接，不再提供安装入口；本目录仅作历史记录。

## 核心变更（相对 V7.0.0）

### 🆕 新增：在线更新检查
- 启动时通过 Base64 解码获取仓库链接，调用「获取 URL 内容」拉取 `version.json`
- 比对 `versionCode`（整数比较）检测是否有新版本
- 有更新时展示 `changelog` 更新要点，并提供新版获取入口（iCloud 链接 + 仓库 `.shortcut` 直链）

### 🔧 改进：正则字典迁移
- 五套正则（快递平台 / 取件码 / 运单号 / 取件地址1 / 地址2）从 config 字典的「正则表达式」子字典迁移至「配置」子字典
- **正则内容零改动**，仅位置调整，为后续集中管理做铺垫

### 📦 动作规模增长
- 93 → 115 个动作（+22），增量几乎全部来自在线更新检查模块（URL 获取 → 字典检测 → 版本比对 → 结果展示 的条件链）

### 📋 沿用
- 取件码 / 运单号 / 取件地址 / 快递平台 正则规则全部沿用 V7.0.0，无任何修改
- 短信自动化触发、提醒事项「待取件📦」写入、去重打勾、系统通知等核心逻辑不变

## 与 V7.1.3 的差异（当前发行版）

V7.1.3（2026-08-12，150 动作）在 V7.1.0 的骨架上做了六处精细化，正好补齐那 35 个动作：

| 能力 | V7.1.0 | V7.1.3 |
| --- | --- | --- |
| 在线更新检查 | ✅ 有 | ✅ 有（优化：关闭后改通知推送，不再 `Exit` 中断运行） |
| 五套正则字典 | ✅ | ✅ 扩展为**六套**（新增尾号 + 特殊格式取件码） |
| 尾号匹配 | ❌ | ✅ `(?<=尾号为?)…(?=快件)` |
| 特殊格式取件码 | ❌ | ✅ 覆盖 `4、4、3486` 等不规则格式，连接符统一 `-` |
| 显示格式可选 | ❌ | ✅ 字典「显示格式」控制三要素排列 |
| 短信匹配机制 | 需含快递公司名关键词，否则退出 | 四参数（取件码/运单号/尾号/特殊格式）全无才退出 |
| 快递平台变量 | 需同时含 `【` `】` | 不再强制，无平台名兜底「未知包裹」 |
| 自动创建列表 | ❌ | ✅ 字典「自动创建列表」开关（默认 True） |
| 动作数 | 115 | 150 |
