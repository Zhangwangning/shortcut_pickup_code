# 快递取件码 V8.0.2 更新说明

这版主要修两个问题，都是 V8.0.1 带出来的。

## 一、V8.0.1 里一个码都抓不到

V8.0.1 的「配置.取件码」存成了双反斜杠（`\\d`）。正则里这表示"字面反斜杠加字母 d"，不是数字，所以整条公式一条都匹配不上。

修完之后恢复正常。这也是为什么 V8.0.1 你测的时候可能是空的。

## 二、凭证里混进了尾号

V8.0.1 把取件码、运单号、尾号、特殊格式合并成一条公式。问题出在：

```
【韵达快递】请凭0425-0007到…取运单尾号1409包裹
```

取件码在前、尾号在后，两个都被匹配到，最后拼成 `0425-0007、1409`。

现在拆成两层：

- **主层**（取件码 + 特殊格式）：命中就用它，多码照样全保留
- **备用层**（运单号 + 尾号）：只有主层完全没结果时才启用

上面那条现在是 `0425-0007`。另一条 `请用1-5-6539…尾号6539` 现在是 `1-5-6539`。

拆开之后有个额外好处：一条短信两个包裹的还能一次提两个，`取件码为 4-5370，4-5409` 出来就是两个码。

## 三、地址去掉外层括号

整段被括号包住的地址，现在会剥掉外壳：

```
(北门架子上)  →  北门架子上
```

括号夹在中间的不动：

```
汇鑫秀水豪园南区店面97号（沙洲菜市场过小永波生鲜超市往前100米）  →  原样保留
```

## 四、不做地址导航了

V8.0.1 里试过做一个「地址导航」开关，把地址填进提醒事项的链接位置。

这个功能这版删掉了，开关和背后的逻辑一起移除。以后也不做。

## 五、要求 iOS 27 以上

没变。iOS 26 及以下装不了。
