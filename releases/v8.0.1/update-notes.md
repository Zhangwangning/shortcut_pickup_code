## 它是怎么跑起来的

它不是自己会动的。真正让它跑的是 iPhone 的「自动化」。

在「快捷指令」App 里建一条自动化规则，触发条件选「收到短信时」。之后每来一条短信，iPhone 就在后台把它跑一遍，不用你点、不用开 App。

跑起来之后：拿到短信原文 → 判断是不是快递短信（不是就退出，不打扰你）→ 从里面挑出取件码、哪家快递、去哪取、几号柜 → 写成一条提醒事项。

全程在手机上，不联网。

所以它依赖两样东西：iPhone 收到短信，加上「快捷指令」App 的自动化。自动化那一步你在 App 里建一次就行，之后一直有效。

## 一、能看出是哪家快递了

以前提醒事项第二行写的是短信开头的【拼多多】。可你到驿站，人家问"哪家快递送来的"，你答不上来。

现在会去正文里找真正的承运方。那条拼多多的短信,正文写的是"您的**圆通**快递",现在就显示圆通快递;妈妈驿站的短信写了"2单元**圆通**",就显示圆通快递。

103 条真实短信里有 69 条能认出公司。其中 34 条跟以前显示的完全不一样：

```
拼多多   →  圆通快递
妈妈驿站 →  圆通快递
兔喜生活 →  邮政
欢猫驿站 →  韵达快递
```

## 二、有几号柜就写出来

"到 2 号柜取"这种短信,柜号会跟在取件码后面：

```
0425-0007·2号
圆通快递｜张掖市甘州区馨月湖小区南门兴裕隆超市
```

到店直接看第几号柜就行,不用在长地址里翻。没有柜号的短信就还是只写取件码,不会多出个空的分隔符。

## 三、地址能点开导航

多了一个"地址导航"开关,默认是开的。开启后每条提醒事项的链接位置会自动填好地图地址,点一下直接跳到地图。

地址为空时会跳过,不会生成那种点了没反应的半截链接。

## 四、地址干净了

以前偶尔会冒出这种：

| 以前 | 现在 |
|---|---|
| `东冠逸品龙湾3号楼底商快递驿站2号柜（请前往` | `东冠逸品龙湾3号楼底商快递驿站2号柜` |
| `家门口签收` | `家门口` |
| `预约时间上门` | 空（这是京东售后的短信,没有取件点） |
| `店扫` | 空（"到店扫码亮灯取快递"被切断的碎片） |

## 五、银行短信不再被当成快递

这条以前挺烦人的：

> 【兰州银行】您尾号 4920 的敦煌卡于 06月08日 17时01分 手机银行转出人民币996.75元…

尾号 4920 被当成取件码写进了提醒事项。整个短信库里这种误抓有 9 条,现在一条都抓不到了。

同时 21 条真正的快递尾号（"取运单尾号7872""快递尾号4320"）全都还在,没被误伤。

## 六、指令轻了一点

取件码、运单号、尾号、特殊格式这四种码,原本是四套分开的规则。现在并成一套,动作数从 138 减到 133。

对使用没影响,就是跑起来利索一点。
