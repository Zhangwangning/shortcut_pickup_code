# V4.0（2025-03-22）

> **发布者**：极客ZHANG
> **发布日期**：2025-03-22
> **发布平台**：小红书
> **前版**：V3.0（2025-03-12）
> **后继**：V7.0.0 / v6.4.x

## 概述

V4.0 是「快递取件码」快捷指令的**第二个公开发布版本**，在 V3.0 基础上引入了**去重**和**拆分短信**两大核心架构升级，标志着作品从"能用"迈向"好用"的关键分水岭。

## 核心更新

### 1. 去重机制（最大创新）
- 遍历提醒事项列表，逐条比对备注字段
- **重复件处理**：通知用户 → 完成旧提醒事项 → 记录新提醒事项
- **新件处理**：直接新建提醒事项
- 解决了 V3.0 重复短信反复添加的问题

### 2. 拆分短信
- 支持一条短信包含多个包裹信息时逐条拆分处理
- 每个包裹独立走完整提取→去重→记录流程

### 3. 输出格式增强
- 提醒事项标题格式：`【物流公司】取件码`
- 备注内容包含：取件地址 + 原始短信 + 链接
- 部分快递自动附带查询链接（如菜鸟/近邻宝）

## 技术特征

| 项 | V3.0 | V4.0 |
|---|---|---|
| 动作数 | ~20 | ~40-50 |
| 正则管理 | 硬编码 Match 动作 | 硬编码 Match 动作（未改） |
| 取件码匹配 | `\d+` 兜底 | `\d+` 兜底（未改） |
| 排除手机号 | 无 | 无 |
| 去重 | ❌ | ✅ Repeat 遍历+比对 |
| 多包裹拆分 | ❌ | ✅ |
| 输出目标 | 提醒事项「待取件」 | 提醒事项「待取件」（格式更丰富） |
| 运单号/尾号独立类 | ❌ | ❌ |

## 与前后版本的关系

```
V3.0 (2025-03-12) ──→ V4.0 (2025-03-22) ──→ V7.1.0 (后续)
   粗糙原型              去重+拆分             正则工程化
   ~20 动作             ~40-50 动作           ~150 动作
   硬编码               硬编码                字典集中管理
   无去重               ✅ 去重               ✅ 智能去重打勾
   3条自动化            (推测优化)            1条【触发
   \d+ 兜底             \d+ 兜底              排除手机号前瞻
   提醒事项             提醒事项(丰富格式)     备忘录📦
```

**V3.0 → V4.0 的跨越 = 去重 + 拆分短信**
**V4.0 → V7.x 的跨越 = 正则工程化（6 套专业正则 + 字典管理 + 优先级链）**

## 备注

- V4.0 的去重架构（遍历→比对→完成旧/建新）被后续所有版本继承并强化。
- 小红书帖子获得 7 赞，174 条真实使用记录证明该版本已有稳定用户群。
- 正则仍为硬编码、无优先级链、`\d+` 兜底仍会误吃电话号——这些问题在 V7.x 系列中彻底解决。
