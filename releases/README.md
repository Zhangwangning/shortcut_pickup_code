# 版本归档 (releases)

本目录按版本号归档快捷指令。其中 **V7.1.3 是当前发行版**，含二维码；V7.1.0 为上一版发行版；V7.0.0 及 v6.4.x 为历史版本的文档记录（仅 `info.md`，无独立安装包）。

> **默认显示最新版**：打开仓库根目录 [`README.md`](../README.md) 即可看到最新版（V7.1.3）的二维码与 iCloud 链接；本目录用于回溯历史版本。

### 📜 历史版本获取方式（V7.1.3 之前）

V7.1.3 之前的版本（V7.1.0、V7.0.0 及 v6.4.x）通过以下方式获取：

- **V7.1.0 / V7.0.0**：仓库 `releases/` 目录下有对应二维码和安装包，可直接扫码或下载。
- **v6.4.x 及更早**：通过**微信公众号关键词自动回复**分发——微信搜索并关注公众号「**极客 ZHANG**」，在对话框中**回复 `0525`** 即可自动获取对应版本的快捷指令链接。

自 V7.1.3 起改为仓库扫码 / iCloud / 仓库下载方式。

## 发版约定

每次优化更新快捷指令后：

1. 在 `releases/` 下新建 `vX.Y.Z/` 目录；
2. 放入该版本的 `qrcode.jpeg`（二维码）、`pickup-code.shortcut`（安装包，可选）与 `info.md`（说明）；
3. 更新根目录 [`README.md`](../README.md) 顶部为最新版的二维码与 iCloud 链接；
4. 更新根目录 [`version.json`](../version.json) 的 `current` 字段（版本号 / versionCode / changelog）；
5. 在 [`CHANGELOG.md`](../CHANGELOG.md) 追加该版本条目；
6. 提交并推送，打上 `vX.Y.Z` 标签（可同步发布 Gitee 发行版）。

> 机器可读的版本信息见根目录 [`version.json`](../version.json)，供快捷指令在线更新检查。
