# 历史版本归档

本目录存放「快递取件码」快捷指令各历史版本的截图、说明与资料。

## 版本列表

| 版本 | 发布日期 | 状态 | 内容 |
|---|---|---|---|
| **V3.0** | 2025-03-12 | 历史归档 | 首个公开发布版，5 张截图 + 完整说明 → [V3.0/](./V3.0/) |
| **V4.0** | 2025-03-22 | 待补图 | 引入去重 + 拆分短信架构（图片待归档） |
| V7.0.0 / v6.4.x | — | 仅文档记录 | 无独立安装包，详见仓库根目录 releases 文档 |
| **V7.1.3** | 2026-08-12 | **当前发行版** | 二维码 + 说明 → [v7.1.3/](./v7.1.3/) |

## 版本演进线

```
V1.0 / V2.0  →  内测自用（未公开）
     ↓
V3.0 (2025-03-12)  →  首发公开：硬编码正则、无去重、提醒事项输出
     ↓
V4.0 (2025-03-22)  →  新增：去重循环、拆分短信、重复通知
     ↓
V7.0.0 / v6.4.x   →  过渡期（仅文档记录）
     ↓
V7.1.0 → V7.1.3   →  正式发行：6套字典正则、优先级链、备忘录📦输出、在线更新
     ↓
V7.2.0 (内测)      →  开发中：尾号优化、地址分化、关键词过滤
```

## 获取方式

- **V7.1.3 及之后**：仓库根目录 `qrcode.jpeg` 扫码 + iCloud 链接下载
- **历史版本（V3.0 / V4.0）**：仅作史料留存，不再提供安装包。如需了解早期版本设计，查看对应版本目录的截图与说明即可。
