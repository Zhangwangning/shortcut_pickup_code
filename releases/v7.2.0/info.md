## 二、相对 V7.1.3 的真实改动（实测对比 `parsed_420.json`，共 3 类）

### ① 尾号公式优化（唯一改动的正则）
| 版本 | 尾号正则 |
|------|---------|
| V7.1.3 | `(?<=尾号为?)…\d{4,})(?=快件)` —— 带尾随 `(?=快件)` 断言，无数字边界、无支付词排除 |
| V7.2.0 | `(?<=尾号为?)…\d{4,})(?!\d)(?!.*(?:支付\|快捷\|银行卡\|消费\|交易\|转账))` |

**改动点**：去掉 `(?=快件)`、新增 `(?!\d)`（防吞尾随数字）、新增金融关键词排除。
**解决**：V7.1.3 **漏抓 6/8 位尾号** + **误抓支付/银行卡尾号**。

### ② 新增「关键词」配置类
- V7.2.0 字典新增 `关键词` 键（V7.1.3 无此键），用于短信分类/标签的可配置关键词。

### ③ 字典组织重构
- Dictionary action：V7.1.3 用 **2 个**（配置分散）→ V7.2.0 合并为 **1 个**。
- 键名归一：`取件列表名称`→`列表名称`、`更新链接`→`更新`。
- 新增顶层键 `自动化`（自动化相关配置独立出来）。

## 五、工作流机制分解（136 动作，按真实执行顺序）

| 阶段 | 动作索引 | 机制 | 关键设计 |
|------|---------|------|---------|
| ① 触发 | iOS 自动化 | 信息含「【」→ 运行指令，输入=「输入快捷指令的信息」 | 无需手动 |
| ② 配置+输入 | i1–3 | Dictionary 载入配置；Get Text from Input 取短信→Set Variable | 配置字典（15 键）一次载入 |
| ③ 取件码类优先级链 | i4–8 | 5 个 Text Match：取件码→运单号→尾号→特殊格式取件码→**关键词** | 命中即止 |
| ④ 优先级判断 | i9–15 | If 逐级下探，全未命中则 Exit 退出 | 保底不误处理 |
| ⑤ 在线更新检查 | i16–23 | Base64 解更新URL→Get Contents of URL 拉 version.json→比对版本号 | 有新版则 Show Notification |
| ⑥ 列表准备 | i24–52 | 取列表名、Filter/Create「待取件📦」、首次自动建列 | 列表不存在则新建 |
| ⑦ 多取件拆分 | i53–71 | Text Split 按分隔符拆多条→Repeat with Each 逐条 | 解决一条短信多包裹 |
| ⑧ 取件地址类优先级链 | i88–93 | 地址1 Text Match→地址2 Text Match（命中即止） | 独立优先级链 |
| ⑨ 文本组装 | i72–99 | Text Replace/Combine 按「显示格式」键拼文案 | True：`【平台】取件码\n地址`；False 反过来 |
| ⑩ 去重+写入+通知 | i100–134 | Filter Reminders→遍历比对→重复则标记旧完成+通知，新则 Addnewreminder→Delay | 智能去重 |

### 三条核心机制
- **机制 A（取件码类优先级链）**：取件码 → 运单号 → 尾号（V7.2.0 已优化）→ 特殊格式取件码 → 关键词，**必须逐级、命中即止**。
- **机制 B（取件地址类优先级链）**：取件地址1（`到达(?:「)?`）→ 取件地址2（`到达?(?:「)?`），**独立、逐级、严禁合并为一条**（V7.2.1 才研究合并为唯一公式，本版本保持两套）。
- **机制 C（去重写入）**：写入前先 Filter Reminders 拉「待取件📦」全部项→遍历比对取件码：已存在则标记旧提醒完成+通知，全新则新增；最后 Delay 错开节奏。

## 九、内测版默认开关（用户可自助开启）

V7.2.0 内测版有**两个功能默认关闭**，按需自行开启：

| 开关 | 字典键 | 默认 | 改为 `True` 的效果 |
|------|--------|------|---------------------|
| 更新检查 | `更新检查` | `False` | 开启在线更新检查（拉 Gitee `version.json` 比对版本号） |
| 自动创建列表 | `自动化` | `False` | 开启自动化创建「提醒事项」App 的「待取件📦」列表（列表不存在时自动新建） |

> **开启方式**：在「快递取件码 V7.2.0」快捷指令的**字典**里找到对应键，把 `False` 改成 `True` 即可。
> 小白用户如不想改，可保持默认——手动建好「待取件📦」列表、不开启更新检查也能正常使用基础提取功能。
