## 版本概述

V3.0 是「快递取件码」快捷指令**首个公开发布版本**。此前 V1.0 / V2.0 为作者内测自用、未对外公开。

## 核心架构

### 六步流程
1. **收到短信** → 判断是否包含快递信息（无弃有入）
2. **提取物流公司**（一般名称在【】里面）
3. **提取取件码**（正则多条件匹配，去除电话或其他号码）
4. **提取取件地址**（一般在"到"、"暂存"、"来"等词前后）
5. **合并输出**：【物流信息】取件码 / 取件地址 / 备注（原短信）
6. **设置自动化**：收到含特定词语/特定发送方的短信时立即运行

### 技术特征
- 正则全部**硬编码**在 Match 动作中（无字典/配置概念）
- 取件码靠 `\d+` 兜底（会误吃电话号码）
- 无独立运单号/尾号/特殊格式取件码分类
- 取件地址仅单条正则
- **3 条独立自动化**分别监听不同关键词（未合并为【触发）
- 输出目标：**提醒事项 App「待取件」列表**
- 无去重逻辑（重复短信会新建重复条目）
