# 快递取件码 V8.0.3 更新说明

三处小修，都是实际遇到的短信。

## 一、「取件码：「A-9182」」抓不到

以前公式的锚点里有「取件码「」，也有「取件码：」，但没有两个连在一起的。

所以这条短信一个码都提不出来：

```
【菜鸟驿站】您的包裹已到店，取件码：「A-9182」，请及时领取。
```

补了一个分支，覆盖「取件码」+ 可选的「为/是」+ 可选冒号 + 左引号（中文直角、英文双引号、中文左双引号都认）。

四种写法现在都能提：

| 写法 | 结果 |
|---|---|
| 取件码：「A-9182」 | A-9182 |
| 取件码「A-9182」 | A-9182 |
| 取件码：A-9182 | A-9182 |
| 取件码:"A-9182" | A-9182 |

这个分支绑定了「取件码」这个词，所以不会去抓别处的引号内容。实测「凭「16359240」到「电力大厦宾馆后门A23」取件」还是取 16359240，没被后面那个引号里的 A23 抢走。

## 二、地址尾部挂着半个括号

```
【微快递】凭取件码199480，前往东冠·逸品龙湾3号楼底商快递驿站2号柜
        （请前往自提）超72小时收费快递柜02-23格口取您的包裹
```

以前地址会带着「（请前往」这半截：

```
东冠·逸品龙湾3号楼底商快递驿站2号柜（请前往
```

现在在「（请前往」处断开：

```
东冠·逸品龙湾3号楼底商快递驿站2号柜
```

只认「（请前往」这四个字，所以「汇鑫秀水豪园南区店面97号（沙洲菜市场往前100米）」这种有用的括号补充不受影响。

## 三、单字地址不要了

「您的包裹已到**店**，取件码…」这种，地址只取到一个「店」，写在提醒事项里没意义。

现在整段地址只有 1 个字就直接清空，第二行只剩快递公司。

清空动作放在去括号之后——因为 `(北)` 本身是 3 个字符，「1 个字」判不出来，得先剥成「北」再判。顺序反了会残留。
