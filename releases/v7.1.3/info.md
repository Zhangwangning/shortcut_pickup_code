## 更新内容

### 🆕 新增 / 改进

1. **版本更新检查优化**
   - 关闭「更新检查」后，不再中断快捷指令运行，改为通过通知推送新版本提示（标题：「【快递取件码】版本更新通知，请立即更新」），不影响现有版本正常使用

2. **取件码匹配规则精细化**
   - 新增「尾号」匹配：`(?<=尾号为?)…(?=快件)`，支持快递尾号提取
   - 新增「特殊格式取件码」正则，覆盖不规则取件码（如 `4、4、3486` 等含顿号、逗号的非标准格式）
   - 取件码连接符统一规范为 `-`

3. **显示格式可选**
   - 新增字典「显示格式」（True/False），控制「快递平台」「取件码」「取件地址」三要素的排列顺序：
     - `True`：【快递平台】取件码 / 取件地址
     - `False`：取件码【快递平台】 / 取件地址

4. **短信匹配机制优化**
   - 旧版：强制匹配短信中是否包含快递公司名称关键词，不存在则停止运行
   - 新版：检测四个参数（取件码 / 运单号 / 尾号 / 特殊格式取件码），**四者全部不存在**才停止运行，兼容性大幅提升

5. **快递平台变量优化**
   - 正则 `(?:【)\w+】` 保留，但不再强制要求短信同时包含 `【` 和 `】`
   - 无平台名时自动兜底为 `【未知包裹】`，解决无【】包裹短信无法识别的问题

6. **自动创建列表开关**
   - 新增字典「自动创建列表」（True/False，默认 True）
   - 首次导入时自动在提醒事项 App 中创建「待取件📦」列表
   - 若不需要可改为 False 关闭此功能
